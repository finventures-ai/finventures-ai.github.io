## Manychat (Instagram) — config cible

1. Un mot-clé = un flux (case-insensitive).
2. Premier message : livrer le lien + divulgation + STOP.
3. Deuxième message (optionnel, +2 min) : invitation à s'inscrire à l'infolettre (opt-in LCAP).
4. TikTok / YouTube : même table, envoi manuel jusqu'à automatisation.

## À ne plus utiliser

- « Commente **MOT** » / « comment **WORD** » générique → remplacé.
- Un seul mot pour toutes les niches → interdit ; toujours choisir dans la table ci-dessus.
